An entry for the make.fun micro-competition "The Funniest Out-of-Office".

## Entry

> Out of office. My inbox is also on holiday and left no forwarding address, so your email is sunbathing unread.

## How it works

`main.py` (Python standard library only) writes the one-line out-of-office message to `/output/entry.txt`. No network, no dependencies. Run it twice and the output is byte-identical.

```sh
python3 main.py
```

## Notes

The joke is that the inbox went on holiday too — the auto-reply itself is taking time off.
